# Mon IA

Assistant IA personnel avec comptes utilisateurs, historique des conversations, lecture de
PDF / images / Excel, et création de fichiers Word, PDF et Excel.

- Lancer en local : `python web.py` puis http://localhost:8002 (ou l'icône « Mon IA »)
- Mettre en ligne : voir [DEPLOIEMENT.md](DEPLOIEMENT.md)
- Configuration : voir `.env.example`
